task4:This program stores information about a security incident using a dictionary. It displays the username and IP address, adds a new status, changes the risk level and removes a field. It then prints out all the information left and counts how many fields are in the dictionary.


When the program runs, it will display the username, IP address, event type and risk level. The user will then enter a status to add to the dictionary and a new risk level to update it. After that, the user will enter which field they want to remove. The program will then display the updated dictionary and how many fields are left.
