task1: 
This program is a security tool that requires users to log in before accessing three features: password counting, brute-force simulation and login authentication. It uses loops and password checks to monitor login attempts and restrict access.

When the program runs, the user must enter the correct username (**admin**) and password (**ross12**) to access the security menu.

The user can then type **1** for option 1 to count how many passwords are correct and incorrect out of 10 attempts.

Type **2** for option 2 to guess the password with 5 attempts.

Type **3** for option 3 to check the username and password, which freezes the account after 3 failed attempts.

Type **4** for option 4 to exit the program.
